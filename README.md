The program implements 4 readability tests for English language:  

Automated readability index (ARI),  
Flesch–Kincaid readability tests (FK),  
Simple Measure of Gobbledygook (SMOG) and  
Coleman–Liau index (CL).  

It reads a file as a command line argument and displays the text statistics -   
number of characters, syllables, words and polysyllabes words and sentences.  
Then at a user request it provides information about one of or all tests scores  
and estimated upper age of a persons who are most likely to understand the text.
